# 跑步教练 Agent · 双主题视觉方案（日间 / 夜间）

> 交付对象：PRAE 平台开发接入
> 身份模型：**三角色** —— 主色 Run Green（健康/出发）· 辅助色 Data Teal（数据/科学）· 强调色 Energy Orange（活力/CTA）
> 设计原则：两套方案**共用同一组件结构与令牌命名**，仅在「配色、明暗度、对比策略」上差异化；语义层在主题间重映射，Primitive 色相阶梯跨主题恒定。

---

## 一、设计语言一致性声明

| 维度 | 日间模式（亮色） | 夜间模式（暗色） | 是否一致 |
|---|---|---|---|
| 组件结构 / 令牌命名 | 同一套 `--rc-*` | 同一套 `--rc-*` | ✅ 完全一致 |
| 三角色身份 | 绿 / 青 / 橙 | 绿 / 青 / 橙（同色相） | ✅ 仅靠明度区分 |
| 深度表达 | 阴影塑形（shadow） | 更浅表面 + 微发光（glow） | ⚠ 策略切换 |
| 文字权重 | 常规 400 | 常规 400（略降感知权重） | ✅ |
| 焦点 / 交互态 | 主色描边 + 柔光 | 主色描边 + 柔光 | ✅ 完全一致 |
| 强调色用量 | 10%（60-30-10） | 10% | ✅ |

> 暗色模式**不是**亮色反转：背景用 `#0E1216`（非纯黑），层级靠「更浅的表面」而非阴影，主色/强调色明度微提以增强暗底可读性。

## 五、可访问性（WCAG AA）

| 组合 | 对比度 | 结论 |
|---|---|---|
| 日间正文 `#16201C` / `#F6F9F7` | 15.76:1 | ✅ AAA |
| 日间主色按钮文字 `#05291D` / `#16C784` | 7.11:1 | ✅ AA |
| 日间弱化 `#6A746D` / `#F6F9F7` | 4.57:1 | ✅ AA |
| 夜间正文 `#EAF0EE` / `#0E1216` | 16.29:1 | ✅ AAA |
| 夜间弱化 `#828C86` / `#151A1F` | 5.04:1 | ✅ AA |
| 夜间主色链接 `#2BD493` / `#0E1216` | 9.8:1 | ✅ AAA |

**禁忌（已在令牌层规避）**：
- 白字不可用于 `#16C784` / `#FF6A1A`（2.2–2.7:1 失败）→ 一律用深色文字。
- 橙色**不作**小号链接文字（亮底失败）→ 仅作按钮（深色文字）与大面积强调；文字链接统一用青 `--rc-data`。
- 红色/绿色仅作状态填充，不单独以「红字 vs 绿字」传达信息（8% 男色觉障碍）。

## 六、PRAE 平台交付说明

**交付文件**
1. `design/running-coach-web/theme-tokens.css` —— 令牌源（Primitive + Semantic 双层，含 `[data-theme="dark"]`/`.dark` 双触发）
2. `design/running-coach-web/theme-preview.html` —— 双主题实时预览（右上角切换，已部署可演示）
3. `design/running-coach-web/双主题配色方案.md` —— 本文件

**接入方式**
- 全局引入 `theme-tokens.css`，在 `<html>` 或根容器设置 `data-theme="light|dark"`（默认 light）。
- 切换主题仅需改 `data-theme`，无需改组件代码（语义令牌自动重映射）。
- 与现有 Web 应用兼容：已保留 `--rc-primary` / `--rc-sidebar-*` 等旧别名指向新语义令牌，可增量替换 `static/theme.css`。

**图表 / 强度区间**
- 图表取色顺序：`--rc-chart-1..5`（绿/青/橙/琥珀/红），暗底自动提亮同色相。
- 心率区间：`--rc-zone-1..5`（绿单色相 5 级阶梯），跨主题一致可读。

**组件级一致性保证**
- 所有组件（按钮、卡片、徽章、输入、导航、图表）仅消费语义令牌，不写死 HEX。
- 因此「换主题 = 换语义映射」，组件结构与间距、圆角、字号、动效两套完全共用。

## 七、一句话总结

> 日间以「清新近白 + 阴影塑形 + 高饱和三角色点题」呈现活力与健康；夜间以「非纯黑深底 + 浅表面分层 + 品牌微发光 + 同色相提亮」保证可读与舒适。**两套仅差在明暗与对比策略，设计与组件语言百分之百一致** —— 这正是双主题系统应有的样子。
