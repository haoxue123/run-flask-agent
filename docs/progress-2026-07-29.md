## 四、已落地但未提交的重点新功能

1. **结构化 JSON 输出 + 反思自检重试**：`generate_training_plan` 现在要求 LLM 返回 JSON 对象，并用 reasoner 核对「用户指令是否被落实」，未落实则回灌重试一次。彻底解决早期「命令不被听从」的问题。
2. **教练路由大幅扩展**：轻量问候短路（跳过 RAG+LLM）、计划生成命令直接拦截生成、参考来源解析为可点击卡片、mem0 长期记忆注入、工具循环（TOOL 标记→skills）、TRIMP/ACWR/就绪度指标、计划执行配速偏差分析。
3. **Garmin Connect 自动同步**：启动时拉一次 + 每 6 小时刷新（APScheduler + garth-ng，支持中国区、OAuth 令牌持久化）。
4. **mem0 跨会话长期记忆**：自动从对话抽取用户事实（伤病/偏好/限制），下次对话与生成计划时检索注入。

这四项都**代码完整且导入通过**，但都依赖外部密钥/网络，本环境未做真实端到端实测（仅确认优雅降级不报错）。

6. **【低】部署需重新构建**：`deploy/` 已就绪，但最新改动未重新 build/推送；自定义域名仍待 ICP 备案（记忆结论）。
