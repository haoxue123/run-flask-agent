# 简历展示方案 · 零成本落地（第一性原理）

## 0. 第一性原理：展示 ≠ 部署

部署的本质是「公网 7×24 常驻 + 持久化 + 运维」，所以要买服务器。
面试展示的本质是「**面试官在需要时能验证你的产物**」，只需「按需可验证的产物」。

| 维度 | 部署（要花钱） | 展示（可零成本） |
|------|------|------|
| 可用性 | 7×24 公网 | 面试时 / 点开链接即看 |
| 持久化 | 必须 | 产物一次性生成，存网盘/仓库即可 |
| 运维 | 要 | 几乎不要 |
| 月成本 | ~60 元起 | **¥0** |

→ 用「视频 / 静态页 / 代码仓库 / 实时演示」替代常驻服务器，**说服力不降反升**。

---

## 1. 可独立交付的展示形式（零 / 极低成本）

### 1.1 视频 Walkthrough（录屏 + 旁白）⭐ 首选
- **技术路径**：本地 `python app.py` 跑通 → OBS Studio（免费）或系统录屏 → 录 3–5 分钟 → 导出 MP4。
- **脚本结构**：① 第一性原理开场 30s → ② 导入 GPX/TCX → ③ 生成训练计划 → ④ 反思审查对比 → ⑤ 教练对话。
- **托管**：Bilibili（国内友好）/ YouTube（外企友好），均免费。
- **成本**：¥0。
- **说服力**：★★★★★（最强——展示真实可运行的 AI 闭环与真实输出）。
- **注意**：录前用示例数据跑通，确保 DeepSeek 调用成功、无卡顿；备一份本地副本防链接失效。

### 1.2 交互式静态 HTML Demo（mock 数据）⭐ 次选
- **技术路径**：把 Flask 5 个页面抽成静态 HTML/CSS/JS；训练计划 / 教练对话用**预录 JSON 假数据**驱动，保证点击有响应、无需后端、无需 Key。
- **托管**：Gitee Pages（国内免费、访问稳）/ GitHub Pages（外企）/ Vercel / Netlify（免费）。
- **成本**：¥0（自定义域名可选 ~50/年，非必需）。
- **说服力**：★★★★（可靠、可点、随时看；弱点是 AI 真实性靠录制数据背书，非实时）。
- **适用**：设计 / 产品岗最友好。

### 1.3 可点击原型链接（静态站点 / 截图热点）
- **技术路径**：静态 HTML 加锚点跳转，或用 Figma 免费版拼 click-through 原型。
- **托管**：同 1.2。
- **成本**：¥0。
- **说服力**：★★★（展示信息架构与流程，弱于真实运行）。

### 1.4 公开代码仓库（GitHub / Gitee）
- **技术路径**：清理 `.env` 等敏感信息 → 公开仓库 → 写好 README（第一性原理 + 架构图 + 部署方案链接）。
- **成本**：¥0。
- **说服力**：★★★★（技术岗极强；产品 / 设计岗中等，证明执行力）。
- **注意**：把 `DEPLOYMENT_PLAN.md` 也放进 repo，作为「产品决策」的硬证据。

### 1.5 面试实时演示（Live Screen-share）
- **技术路径**：面试时本地起服务 + 共享屏幕，真实调用 DeepSeek。
- **成本**：¥0（已有代码 + DeepSeek 免费额度）。
- **说服力**：★★★★★（最强且零成本），但依赖网络 / API 稳定，**务必备录屏兜底**。

### 1.6 作品集一页纸（Bonus，国内极友好）
- **技术路径**：腾讯文档 / 飞书文档，内嵌视频链接 + 仓库链接 + 关键截图 + 第一性原理摘要。
- **成本**：¥0。
- **说服力**：★★★★（ recruiter 点开即懂，无需技术背景）。

### 说服力总排名
Live 演示 ≈ 视频 Walkthrough ＞ 交互 HTML Demo ≈ 公开仓库 ＞ 静态原型 ＞ 一页纸（一页纸胜在触达效率）

## 2. 简历写法与结构

**原则**：用「问题 → 第一性原理 → 决策 → 可验证交付」四段，4–6 行内同时呈现产品思维与成果。

### 2.1 通用模板（可直接复制）

```
马拉松训练计划 Agent ｜ 独立产品项目（从 0 到 1） ｜ 2026
· 问题与第一性原理：跑步者难把真实运动数据转化为可执行训练计划。
  拆解为「感知→推理→行动→反馈」闭环，定位 Agent = 工具使用 + 反思。
· 方案与交付：基于吴恩达 Agentic 模式设计双模型架构
 （deepseek-chat 生成 + deepseek-reasoner 反思审查），落地 Flask Web 应用，
  覆盖数据总览 / 深度分析 / 训练计划 / 趋势 / 教练对话 5 大模块；输出完整 PRD + 部署方案。
· 产品决策：基于第一性原理评估国内外 / Serverless 差异，因应用有状态
  （本地文件 + 向量库）选定轻量云服务器方案，规避临时磁盘丢数据风险，并给出六维度落地设计。
· 验证：可交互 Demo（视频）+ 公开代码仓库，覆盖端到端闭环。
```

### 2.2 产品岗变体（突出权衡与决策）
- 强化：问题拆解、第一性原理、部署方案的权衡取舍、用户价值。
- 关键词：`第一性原理` `权衡决策` `有状态 vs Serverless` `用户闭环` `可验证交付`。
- 把部署方案作为「产品判断力的证据」单独一句点出。

### 2.3 设计岗变体（突出 IA 与体验）
- 强化：信息架构、三令牌身份冲突（引用 `跑步Agent配色方案研究.md` 的绿青橙三角色推导）、
  Coach Orb 签名资产、计划月历 / 教练对话交互。
- 关键词：`信息架构` `设计语言统一` `交互闭环` `可点击 Demo`。
- 必附：可点击原型链接 / 一页纸作品集。

### 2.4 技术岗变体（突出架构与工程）
- 强化：Agent 架构（工具使用 + 反思）、双模型分工、Flask / Docker / CI/CD、
  第一性原理部署（有状态识别、单卷持久化）。
- 关键词：`Agentic 设计模式` `双模型` `Docker 编排` `CI/CD` `第一性原理部署`。
- 必附：公开仓库 + 部署方案文档链接。

## 3. 分岗位侧重调整建议

| 岗位 | 最该放的前端证据 | 简历叙述重心 | 推荐展示组合 |
|------|------|------|------|
| 产品 | 视频 Walkthrough + 部署方案文档 | 问题拆解 / 第一性原理 / 权衡决策 | 视频(B站) + Gitee 仓库 + 一页纸 |
| 设计 | 可点击原型 + 设计分析文档 | IA / 设计语言统一 / 交互闭环 | 交互 HTML(Gitee Pages) + 一页纸 |
| 技术 | 公开仓库 + 部署方案 | 架构 / 双模型 / Docker·CI/CD | GitHub 仓库 + 交互 HTML(Vercel) + Live 兜底 |

---

## 4. 推荐落地组合（全部 ¥0）

**国内岗**：视频(B站) + Gitee 公开仓库 + 腾讯文档作品集一页纸
**外企 / 技术岗**：视频(YouTube) + GitHub 仓库 + 交互 HTML(Vercel)
**通用兜底**：面试时本地 `python app.py` 实时演示（备录屏）

> 仅当想要品牌域名时才花 ~50 元/年；展示本身零成本即可完整呈现产品方案。
